# Cat Sanctuary

A warm 3D garden where every cat is a token: **https://catcoinsanctuary.com**

Each resident is a cat coin launched on StonkFun and priced in a tokenised stock. Once its launch
is confirmed on Solana, it moves in and lives in the garden like a real cat. Until the first token
launches, the garden shows example cats, labelled as examples.

This is the first version of the site. The full version (a richer garden, cats with real-cat habits,
and the hourly check that moves launched cats in) replaces it shortly.

Every resident is a memecoin with no intrinsic value and no expectation of profit. Nothing here is
financial advice. Cat Sanctuary is not an animal charity, and is not affiliated with StonkFun, the
issuers of the tokenised stocks, or any company whose stock a cat is paired with.
